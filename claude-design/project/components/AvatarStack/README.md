# AvatarStack

Overlapping avatars (−8px) with a surface stroke. It shows at most four, then "+N". On photos, set `onImage` to switch the stroke and "+N" to glass.

**Props:** `members`, `size`, `max`, `onImage`.

**Motion:** someone joining after the stack first appears pops in on the playful spring and "+N" bumps. The faces already there when the screen opens just appear. No haptic: other people's changes never buzz.
