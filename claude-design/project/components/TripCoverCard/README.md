# TripCoverCard

The trip's face: a 4:5 photo with `radius-lg`, the trip name in `display` (Newsreader) bottom-left on the scrim, a status glass chip top-left and the travelers' avatar stack bottom-right. With no photo it falls back to a `sunken` card with the name in ink.

**Props:** `title`, `subtitle` ("12–17 Jun · Lisbon"), `image` (the group's cover photo), `status`, `members`, `aspectRatio`.

- Use the group's own photo, never stock.
- Never lay color blocks over the photo.
