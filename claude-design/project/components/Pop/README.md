# Pop

Scales its child in on the playful spring (0 → ~1.05 → 1). **People moments only:** an avatar joining a plan, a needs-you dot arriving, your face dropping into a vote. At most one per screen. Reduced motion fades it in over 120ms instead.

**Props:** `delay` (ms), `children`. Flutter: `TPPop` (give it a new key to play again).
