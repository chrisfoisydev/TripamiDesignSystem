# UnderlineTabs

Text tabs with a 2px `accent` underline on the active tab and a hairline under the row. Use them to switch views within a screen, for example Upcoming · Planning · Past.

**Props:** `labels` (string[]), `value`, `onChange(index)`.

Keep labels to one word. Use at most four tabs. **Haptic:** selection tick when the tab changes; tapping the current tab is silent.
