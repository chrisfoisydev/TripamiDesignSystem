# Icon

Phosphor icon, drawn in `currentColor`. Use regular by default and `fill` only for the active tab or a toggled state.

**Props:** `name` (one of `Tripami.iconNames`), `size` (22 in rows and nav bars, 18 for chevrons and inline status, 24 in the tab bar), `fill`, `label` (when the icon is the only content of a control), `color`.

- Takes the color of the text beside it. Use `accent` only when active or selected.
- Never substitute emoji.
