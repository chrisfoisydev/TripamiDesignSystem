# TextField

Underline text field with an uppercase eyebrow label, like a hotel registration card. Focus thickens the underline to 2px ink. An error turns it `critical` and adds a helper line.

**Props:** `label`, `defaultValue`, `placeholder`, `help`, `error`, `inputMode`, `id`.

- Show what people type exactly as typed. Never uppercase user input.
- Errors say what went wrong and how to fix it.
