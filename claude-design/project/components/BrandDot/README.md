# BrandDot

The brand's playful signature: the orange dot from the logo's "i" drops into place with one small bounce. Use it on the launch screen over a wordmark without its dot, or alone at brand moments. It's `brand-orange`: never a UI state marker.

**Props:** `size`, `delay` (ms, default 120). Flutter: `TPBrandDot`.

A launch animation needs a version of the wordmark without its dot, which the Logos group doesn't have yet.
