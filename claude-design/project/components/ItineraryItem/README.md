# ItineraryItem

A plan on the timeline: time column, rail with a node, then the content. `now` tints the row `accent-subtle` and colors the node and time Lagoon. `booked` adds a seal. `idea` (undecided) uses a hollow node and a secondary title.

**Props:** `time`, `title`, `detail`, `state` (`planned` · `now` · `booked` · `idea`), `addedBy`, `addedWhen`, `reactions`, `footer`, `last`.
