# RoleTag

A small pill for someone's role or status on a trip: `caption` at 600.

- **Neutral** (`sunken`, `text-secondary`) for roles: "Organizer".
- **Pending** (`amber` tone) for something waiting on that person: "Invited".

**Props:** `pending`, `children`.

- Never a navy or orange fill: those mean "action" and "you, now".
- Flutter: `TPRoleTag.neutral` / `TPRoleTag.pending`.
