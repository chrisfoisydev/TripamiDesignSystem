# Icons

Phosphor Icons (MIT), Tripami's curated set: 42 glyphs, each in regular (`name.svg`) and fill (`name-fill.svg`). Each SVG is single-ink near-black `#16171B` on a 256 viewBox; recolor to `text-primary` navy when placing them as images. Use regular by default and fill only for the active tab or a toggled state. In code, prefer `Tripami.Icon` (web) or `TPIcons` / `TPIconsFill` (Flutter), which follow the text color.
